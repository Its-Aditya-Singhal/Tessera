# Store listing (draft)

Text for a future Chrome Web Store submission. Store text must not use other companies' product
names or logos, so it says "AI chat sites" rather than naming them. The README and the in-product
UI can name the supported sites, because that is how users pick a target.

**Name:** Tessera

**Summary (132 characters max):** Sharper prompts, scrubbed secrets and portable chat context for AI
chat sites. Runs on your device, with no servers.

**Description:**

Tessera adds a small panel to popular AI chat sites.

- Prompt check: as you type, rules spot prompts that are missing a task, context or format, and
  suggest what to add. With an optional on-device model, Tessera rewrites the prompt and shows a
  word-by-word diff before you import it. Good prompts are left alone.
- Privacy: API keys, passwords, card numbers, emails, phone numbers, Aadhaar, PAN, UPI IDs and more
  are replaced with placeholders before anything reaches a model or another chat. Paste a secret into
  a chatbox and Tessera offers to scrub it.
- Carry a conversation: move a chat to another assistant as a compact summary with the recent
  messages and every code block, redacted first. You review it and press send yourself.

Everything runs locally. No accounts, analytics or telemetry; only settings are saved. The optional
on-device model downloads only if you ask for it.
